# di-lao · 图床

角色卡状态栏素材图床，公开仓库，供 SillyTavern 正则「状态栏」引用。

仓库分两大块：

| 前缀 | 对应角色卡 |
|---|---|
| 根目录 | 深渊地牢 |
| `监狱/` | 监狱（NEURAL LINK · STATUS 赛博状态栏） |

---

## 一、深渊地牢（根目录）

| 目录 | 内容 | 数量 |
|---|---|---|
| `01_女主立绘/` | 4 位女主立绘（547×799，对应卡片 `aspect-ratio: 13/19`） | 4 |
| `02_NPC随机池/` | 普通 NPC 通用随机立绘池 | 5 |
| `03_固定NPC立绘/` | 按姓名硬绑定的 NPC 立绘 | 2 |
| `04_CG画廊/` | 每位女主 3 张 CG（800×800），按 女主 分子目录 | 12 |
| `05_字体/` | 三套 ZeoSeven 字体自托管副本 | — |

CG 解锁条件：CG1 = 女主专属值 > 333，CG2 = 专属值 > 666，CG3 = 生命刻印结成。

---

## 二、监狱（`监狱/` 前缀）

全部 547×799，与卡片立绘框比例一致。

| 目录 | 内容 | 数量 |
|---|---|---|
| `监狱/01_女主立绘/` | 9 位女主 × 6 张立绘，命名 `<角色>_01.png` … `_06.png` | 54 |
| `监狱/02_NPC随机池/` | 4 个势力各 2 张，命名 `<势力>_01.png`、`_02.png` | 8 |

女主：莉艾丽、娜奥米、艾莉西亚、玛雅、基莉娅、贝阿特丽丝、基拉、朱莉娅、伊丽莎
势力：新地球、新索拉尔、科迪莉亚公国、Die Erde

**立绘槽位 = `avatarIdx`，解锁条件由「洗脑进度」驱动：**

| 槽位 | 解锁条件 |
|---|---|
| `_01` | 始终解锁 |
| `_02` | 洗脑进度 ≥ 125 |
| `_03` | 洗脑进度 ≥ 250 |
| `_04` | 洗脑进度 ≥ 375 |
| `_05` | 洗脑进度 > 0 |
| `_06` | 处于孕育状态（或已解锁过） |

> 注：`艾莉西亚_02.png` 与 `艾莉西亚_03.png` 内容相同 —— 原卡片这两槽位本就指向同一张 postimg 图，为保持槽位编号连续而各存一份。

## 引用方式

jsDelivr CDN（推荐，有缓存加速）：

```
https://cdn.jsdelivr.net/gh/Yehehua1311/di-lao@main/<路径>
```

备用 jsDelivr 节点（主节点被干扰时可换）：

```
https://gcore.jsdelivr.net/gh/Yehehua1311/di-lao@main/<路径>
```

raw 直连（实时，无缓存）：

```
https://raw.githubusercontent.com/Yehehua1311/di-lao/main/<路径>
```

路径中的中文需做 URL 编码，例如
`监狱/01_女主立绘/莉艾丽_01.png` →
`https://cdn.jsdelivr.net/gh/Yehehua1311/di-lao@main/%E7%9B%91%E7%8B%B1/01_%E5%A5%B3%E4%B8%BB%E7%AB%8B%E7%BB%98/%E8%8E%89%E8%89%BE%E4%B8%BD_01.png`
